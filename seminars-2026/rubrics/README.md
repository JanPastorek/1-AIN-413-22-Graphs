# Common rubrics

Use these with the published task and AI zone. Give feedback on the reasoning, not merely a total. Do not grade speed or require an original research discovery.

## Eight-point live practical

| Criterion | 0 | 1 | 2 |
|---|---|---|---|
| Model and assumptions | Wrong/absent model | Usable model with an important omission | Correct model and explicit algorithm assumptions |
| Method and checked witness | No valid result | Partial method or unchecked result | Correct method and independently checked feasible witness |
| Reasoning / certificate | No justification | Relevant but incomplete argument | Valid key proof, bound, or optimality certificate |
| Individual transfer | No justified adaptation | Partly correct adaptation | Correct response to the unseen change, with reason |

The first six points are also individual: each student must explain or write the essential model, witness, and argument after the pair block. The protected response has room for all four criteria. Oral sampling may clarify an answer but does not replace equal access to the written task.

## Three-point proof clinic

One point each for (1) correct statement/model or constructed object, (2) valid decisive argument, and (3) complete conclusion with the relevant scope or hypothesis. A correct guess without justification earns no argument point.

## Two-point exit ticket

One point per stated subquestion. Accept equivalent correct constructions or proofs. No points for stylistic polish. The instructor key specifies what is essential and common partial answers.

## Twelve-point Graphathon

Team portion: model and limitations 2; feasible result with certificate/test 2; clear mathematical explanation 2.

Individual portion: changed-instance model 2; reasoning/certificate 2; justified comparison or algorithm adaptation 2. Team success cannot substitute for this response. Individual written transfer is the default; short oral questions are added only where staffing permits.

## Algorithm-writing feedback (not another score)

Check model, method, invariant, correctness, runtime, and interpretation using the [reasoning guide](../syllabus/reasoning-guide.md). Label missing hypotheses, false converses, unsupported optimality, and input-model assumptions explicitly so students can repair them.
